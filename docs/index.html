Washington traffic uses WSDOT's public real-time detector feed. Outside Washington, Offroader currently falls back to normal routing until another state's traffic adapter is added.

Offroader web preview

This is a browser twin of the Android prototype, not an Android emulator. In Washington, routes are scored against current WSDOT detector speeds. Seattle camera pins use SDOT's official camera inventory.

Traffic data is cached by the Offroader repository so the browser does not need a paid traffic API key.
