Offroader web preview

This is not an Android emulator. It is a browser version of Offroader so you can test the map, U.S. destination search, routing, GPS, and camera layers without installing anything.

Live traffic and the on-device YOLO detector are not enabled in this web preview. Base routing uses the public OSRM demo service.
